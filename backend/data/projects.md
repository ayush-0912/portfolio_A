# Projects

## Leave Management System (Full-Stack Web Application)

Ayush Kukekar built a role-based Leave Management System with separate user and admin workflows. Employees can apply for leave, managers can approve requests, and admins can manage employee-manager assignments and departments.

The Leave Management System implements soft delete and delete locks to ensure data integrity and prevent accidental data loss.

Tech stack of the Leave Management System: C#, .NET, and Angular (TypeScript).

## AI Email Classifier (LangChain / Python)

Ayush Kukekar developed an AI Email Classifier pipeline that automatically classifies emails into 9 categories and tracks embedded task statuses, significantly reducing manual triage effort.

The AI Email Classifier visualizes real-time analytics and task progress through an interactive Streamlit dashboard, improving team workflow efficiency.

Tech stack of the AI Email Classifier: Python, LangChain, Streamlit, and PostgreSQL.

## Detonator Planning System (Full-Stack Web Application)

Ayush Kukekar designed and built the Detonator Planning System, an order management platform for planning and procuring explosive materials. It replaced a manual process with a structured digital workflow.

The Detonator Planning System has features for order creation, status tracking, and inventory management, with a clean, production-ready UI.

Tech stack of the Detonator Planning System: Django, Next.js, PostgreSQL, and Tailwind CSS.
